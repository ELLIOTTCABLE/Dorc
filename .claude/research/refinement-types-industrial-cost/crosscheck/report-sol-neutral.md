## Findings

### High

- conditional-soundness-assumes-composition-correctness — High. The Lean consumer-safety theorem assumes `SoundCompare`, whose definition already asserts that every `same` and `provablyDisjoint` result from the complete `compare` implementation is semantically correct. It therefore proves correct verdict consumption, but not the stronger claimed result that composition bugs cannot cause misfires; that requires generator-level assumptions from which `SoundCompare` is derived. Evidence: `.claude/.../spike-lean-sparing/SparingAlgebra/Laws.lean:160-199,271-280`; `REPORT.md` “modeling-note-conditional-soundness”; `Research/notes/277-entity-algebra-design.md` §2 lines 133-154. +SURE

- claim-tier-upgrades-remain-spellable — High. The analysis calls `claim.rs`’s tier transitions unrepresentable, but `Claim::vouched` is a public generic constructor and observation payloads are publicly recoverable; an explicit `Claim::vouched(measured.into_observation(), Rung::Both)` remains available. Vouch payloads are likewise publicly recoverable and can be mapped into local fact types, so the doctests prohibit selected implicit routes, not authority laundering itself. Evidence: `.claude/research/refinement-types-industrial-cost/turn03-2026-08-13-notes.md:34-40`; `spike/crates/core/src/claim.rs:30-43,94-110,221-298`. +SURE

- formal-model-omits-transport-contract — High. Section 5 requires universal lifting for both consumers, but the formalization implements only set-level sparing; transport remains a single-verdict Boolean with no “every backing member transports” operation or theorem. It also represents the author side as an arbitrary `List Coord`, with only the admin flag represented, so the double-ended clean-claim admission and attribution obligations are assumed outside the theorem statements; the empty-footprint counterexample exposes that missing boundary. Evidence: `Research/notes/277-entity-algebra-design.md` §5 lines 393-450; `spike/CLAUDE.md` “Invariants — separation, worlds & survival” lines 198-233; `SparingAlgebra/Sparing.lean:35-72`; `SparingAlgebra/Laws.lean:86-92`. +SURE

### Medium

- certifier-closes-only-inductiveness — Medium. The proposed checker can establish that one concrete answer is a post-fixpoint relative to the supplied `transfer`, `join`, `leq`, and `Eq`; it does not independently validate those operations or semantic equality because it reuses them. Thus it closes worklist/cap-result errors conditional on a lawful algebra, not all three advertised solver preconditions; the amendments partly recognize this by naming shared lattice operations as trusted. Evidence: `.claude/research/refinement-types-industrial-cost/turn06-2026-08-13-notes.md:12-25,153-165`; amendments ledger lines 72-88; `spike/crates/analysis/src/lattice.rs:31-49`; `spike/crates/analysis/src/solve.rs:59-71`. +SURE

- comparison-order-loses-cross-kind-separation — Medium. Lean checks context equality before kind equality, so different-kind coordinates in different contexts return `unknown`. The written spec says the never-derive-separation carve costs only within-kind cross-context precision and that cross-kind disjointness remains free, so the implementation is conservatively safe but not faithful and loses specified value. Evidence: `SparingAlgebra/Compare.lean:82-103`; `Research/notes/272-address-derived-topology.md` §4 lines 154-171; `Research/notes/277-entity-algebra-design.md` §3 lines 172-181. +SURE

- outcome-generator-ban-is-not-enforced — Medium. `pin-no-outcome-as-generator` says compare results never re-enter the relation as evidence, whereas the Lean tripwire only prevents a global `Coe Verdict EntityRes`; clients can still write an explicit conversion or construct a later `EntityCmp` from previous verdicts. The report admits this limitation, but “all five theorem families proved” overstates the result: this family is neither a theorem nor an enforced architectural separation. Evidence: `Research/notes/277-entity-algebra-design.md` §5 lines 411-427; `SparingAlgebra/Laws.lean:284-298`; `REPORT.md` theorem ledger lines 16-32; amendments ledger lines 99-103. +SURE

- tooling-lanes-lack-an-aggregate-budget — Medium. The combined state places Kani now, Flux early, and an Aeneas/Lean core near-immediately behind a spike gate; each lane’s pin and brittleness is priced separately, but the portfolio does not budget their cumulative upgrade/repair work or define compatibility and exit criteria between the two Rust-nightly consumers. The dedicated opt-in lanes and Aeneas gate reduce this risk, so this is an aggregate-cost defect rather than a contradiction. Evidence: `turn06-2026-08-13-notes.md` portfolio items 2-3; amendments ledger “amendment-aeneas-pulled-forward” lines 72-94; `turn04-2026-08-13-notes.md:18-35`; `turn05-2026-08-13-notes.md` “maturity, churn, proof stability” and citation around line 187. ~SUSPECT

## What holds

- result-certification-is-the-right-narrow-seam — The cited result-certification architecture supports checking a concrete post-fixpoint while leaving worklist heuristics untrusted, and the live solver exposes exactly that seam. A refused certificate can safely prevent plan-time licensing without becoming an expensive host-side runtime net; the amendment’s `Certified | Refused(EdgeWitness)` shape is materially better than a Boolean. Evidence: `turn02-2026-08-13-notes.md` “Findings” and Blazy citations; `turn06-2026-08-13-notes.md` portfolio item 1; `spike/crates/analysis/src/solve.rs:34-116`. +SURE

- kani-properties-are-the-cheapest-win — The live lattice tests use small hand-picked populations, `MapL` convergence depends on canonical structural equality, and the backing universal-meet bug class is finite and logic-shaped. Explicit monomorphic Kani harnesses outside the dependency-clean kernel fit these obligations better than autoharness or refinement annotations. Evidence: `spike/crates/analysis/src/lattice.rs` trait laws, `MapL`, and tests; `turn03-2026-08-13-notes.md:21-33`; `turn05-2026-08-13-notes.md` Kani findings. +SURE

Current production consumers visibly propagate or test `solution.converged`; the research’s “per-consumer obligation” description is accurate. Evidence: `spike/crates/analysis/src/lattice.rs:24-249`; `spike/crates/analysis/src/solve.rs:1-134`; call sites in `analysis/src/{value,funcenv,effect}.rs`. +SURE
