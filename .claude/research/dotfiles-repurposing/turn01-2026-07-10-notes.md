- repurp-finding2 +SURE: localhost-as-target (no SSH — the dominant dotfiles deployment) is

  plan (`142` — grep clean). Nothing *forbids* a local-exec transport; the kFIDELITY leaf
  seam + kCOMMS executorless-OOB should admit it trivially. Gap = never-designed, not baked.
- repurp-finding3 +SURE (r25 verify-errand, LIVING_STATUS): `case "$(hostname)"` poison-walls an
  entire book at HEAD; no read-value command (hostname/uname/whoami) is modeled anywhere in
  the 145-case corpus. Host/OS-branching is THE central dotfiles idiom (per-machine
  variance), so for this cohort the read-value/Query-lane gap is existential, not
  nice-to-have. Fix is already roadmapped (P5 "read-value commands need the Query/predict
  lane") — the audit's contribution is priority re-weighting.
- repurp-finding4 ~SUSPECT: heterogeneity (different PM per machine) is handled by CONTROL FLOW
  in idiomatic sh (`case $(uname)` picks one branch per host), so per-host analysis stays
  single-PM and MH2's cross-PM lattice is NOT on this cohort's critical path — but only if
  repurp-finding3 is fixed (the branch must fold per-host). `command -v x || install` sidesteps
  PM identity entirely; a `command -v` oracle lifts the cohort's main guard idiom.
- repurp-finding5 +SURE: `sudo cmd` is an unmodeled opaque wrapper today (generalizes the r25
  `su - postgres -c` permanent-wall finding). Ops books run as root; personal-machine books
  sudo per-line. Without sudo argv-transparency (deferred-surface item: 23J lane-privilege /
  17N §7 wrapper-context kinds — seam reserved, not baked away) the system-level half of
  every dotfiles book stays walled. Not cheap (privilege changes probe semantics); the
  priciest high-value item for this cohort.
- repurp-finding6 +SURE: the two-users split collapses here — one hobbyist, admin-hat only,
  writes zero oracles. Cohort value = f(stdlib coverage of dotfiles idioms). Current P5
  slice is ops-flavored (apt/systemctl/ufw). Dotfiles slice: ln -s, cp/install, mkdir -p,
  git clone/pull, curl -o, macOS `defaults`, brew (+bundle), chmod, command -v. Mostly
  small, existing machinery.
- repurp-finding7 +SURE: marker-gating (`24M`: unmarked book = plain sh; marker gates syntax
  only) means an EXISTING install.sh gets stage-1 value with zero edits — "point Dorc at
  your install.sh, get a plan" is the killer demo for the script cohort. Off-ramp doubles as
  fresh-machine bootstrap (book runs bare before Dorc exists). Half-B guard-subsumption
  rewards the cohort's existing `command -v … ||` defensive idioms directly (pipe-guard lift
  24J covers `curl|sh`-guarded-installer shapes).
- repurp-finding8 ~SUSPECT: DESIGN's perf posture (network dominates; analysis ~free) inverts
  locally — no tunnel to hide analysis latency behind in a hot loop. kPRECISION/kFACTS are
  low/med lock-in; watch-item, not a bake.
- repurp-finding9 +SURE: native-Windows config management is welded out (kLANG; `139` tier-B
  degrades, WSL is the answer). The one real capability cliff vs chezmoi for heterogeneous
  personal fleets. Eyes-open weld, priced not relitigated.
- repurp-finding10 ~SUSPECT: no host→book direction exists (chezmoi re-add / aconfmgr capture /
  mackup analogs). Product-scope gap, unbaked (probe/predict machinery could feed a degraded
  "here's the diff, paste it" form via the why-lens). Common feature in the space — agents
  to confirm how load-bearing.
- repurp-finding11 -GUESS: interactive prompts (`read` from stdin, chsh) exist in wild dotfiles
  scripts; under Dorc's captured execution they hang/fail. A "book reads stdin" lint is

- repurp-finding12 ~SUSPECT: secrets (op/pass/age pipes) — unmodeled walls today; oracle-able.

- repurp-finding13 ~SUSPECT: oracle-rot risk is higher in this domain (brew/mise/npm churn fast
  vs apt/systemctl stability); fail-toward-run + attribution degrade gracefully but

- repurp-finding14 +SURE: $HOME/~-relative entity coordinates (dominant in dotfiles) are

- repurp-finding15 +SURE: macOS `defaults write` batches (100s of lines in famous repos) are the

## Agent-A (manager landscape) + Agent-C (whole-machine cohort) digests — landed, curated

- repurp-finding26 +SURE (in-corpus, `23D` §3): per-iteration loop verdicts are DEFERRED by the

  loop … so it all folds under 'figure out loops eventually' (per-iteration guarding,
  deferred)." For ops books (straight-line) that deferral is benign; for dotfiles books the

  aconfmgr + winget-DSC-in-theory even claim it; home-manager/Brewfile/topgrade/ansible-pull

  CLI verb at most).
