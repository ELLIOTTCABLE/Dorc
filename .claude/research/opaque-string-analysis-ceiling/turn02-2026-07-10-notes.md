## Working hypothesis for concern-peel-gloss (to test against sources this turn)

hyp-context-transform: "peel + tag" is INSUFFICIENT as stated. Each wrapper is a
*context-transformer*, and the transformations differ per wrapper along at least these
axes (strawman-sh grounded):

- identity/no-op: `nice cmd`, `nohup cmd`, `time cmd` — argv-passthrough, ~pure peel.
- env-transform: `env FOO=1 cmd` (adds), `sudo cmd` (env_reset scrubs by default; `-E`
  preserves), `su - user -c` (login shell = full reset). The nested analysis must run
  under a TRANSFORMED var-plane, not the outer one — peel-without-env-transform is
  *unsound* for var-dependent facts.
- user-transform: `sudo`, `su`, `doas` — $HOME/`~` resolve differently; user-scoped
  state-cells (17N §7's per-context namespace). NOTE: user-as-context-tag is round-1
  territory; privilege *semantics/ecosystem* is round-2, do not stray.
- fs-view-transform: `chroot /new cmd` — every path fact re-roots; `docker exec`,
  `unshare` similar-but-worse. A tag is not enough; path *coordinates* transform.
- host-transform: `ssh host 'STR'` — entire fact-namespace forks to another machine
  (17N §7: "ssh/docker exec ARE Dorc's own execution model"); plus the double-parse
  hazard (local shell expands, THEN remote shell re-parses the joined string).
- argv-binding: `sh -c 'STR' name args` (positional params bind), `xargs cmd` (argv from
  RUNTIME stdin — data-dependent, statically ⊤ in general), `find -exec cmd {} ;` (argv
  from live fs state — same).
- execution-partiality: `timeout 5 cmd` — the child may be KILLED MID-RUN ⇒ effects
  partial ⇒ collides with the atomic-command axiom; a converged-vouch's meaning under
  partial execution is unclear. (Also `ssh` under network failure.)
- outer-shell residue: redirections/pipes attach in the OUTER context before the wrapper
  runs (`sudo cmd > /root/f` writes as the CALLING user — ShellCheck lints exactly this,
  to-verify → SC2024). So even "pure peel" wrappers leave outer-evaluated residue the
  decomposition must keep OUTSIDE the peeled context.

Consequence if hyp holds: the out-of-engine north-star needs oracle-spellable
*context-transformers* (env-map, user, cwd/root, host, argv-binding, partiality), not a
boolean "peel me" — which is a substantially bigger primitive-vocabulary ask, and exactly
where the kCONTEXT flat-domain redline gets tested.
