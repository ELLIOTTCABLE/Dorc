# kWHICHSH GCD research — care-set, feature matrix, Issue-8 pin-downs, candidate rulings

> Turn 01, 2026-07-12. Subagent research for the `kWHICHSH` dialect close.
> Scope: **oracle dialect only** (books out of scope). The stripped oracle (dorc
> annotations erased) must (1) RUN on any plausible host `/bin/sh` and (2) SURVIVE
> being pasted into a consumer's own script under whatever shell they daily-drive.
> Certainty markers per global-prompt rule: +SURE / ~SUSPECT / -GUESS.

---

## 0. The reframe that drives everything (read first)

The knob is posed as two poles — `kWHICHSH-minimum-lcd` (dash+local, one pinned
target) vs `kWHICHSH-maximum-gcd` (true common subset of the shells that matter).
**For the oracle dialect those two poles collapse into nearly the same point**,
and the "delta above dash+local" is *subtractive discipline*, not additive
richness. Reasoning:

- The GCD reading tempts you to *admit* bash/zsh richness (`${x/}`, `[[ ]]`,
  `&>`, arrays) because "all the big shells have it." But the **consumer-paste**
  requirement forbids relying on any of it — the very shells whose richness you'd
  admit have *inversions* (zsh word-splitting, `echo` escapes, ksh93 scoping)
  that make the rich constructs unsafe to depend on. So the maximum-gcd cannot
  actually be spent. +SURE.
- What survives paste into *every* daily-driver is the classic-POSIX defensive
  core **plus `local`** — which is almost exactly the **Debian Policy §10.4**
  `/bin/sh` contract (POSIX + `local` + a couple of carve-outs). +SURE.
- Net: **minimum-lcd ≈ maximum-gcd ≈ "Debian-Policy `/bin/sh`, minus its own
  indulgences (`test -a/-o`, `echo -n`)."** The honest delta above "dash+local"
  is ~5 disciplinary line-items, not a feature set (§4).

This *confirms* the standing r23-h3 lean ("dash-ish, POSIX2024-ish, `local`
carved in") with **one refinement**: "POSIX2024-ish" describes the EXECUTOR
target well but is slightly too generous for the DIALECT floor — three genuine
Issue-8 features (`set -o pipefail`, `$'...'`, the *removal* of `test -a/-o`)
cannot be freely assumed on the paste / old-host side even though they are
"2024-standard" (§3, §4 rows 4/21). The paste-survivable floor is closer to
**"POSIX-2017 + `local` + the *safe* subset of Issue-8."**

## (a) THE CARE-SET

Two cohorts. **Host-sh** = executes the stripped oracle as a script. **Consumer**
= the daily-driver into whose own script the oracle bytes get pasted/sourced.
LOAD-BEARING = dialect must survive it; the ruling changes if it's dropped.

### Host-`/bin/sh` cohort (must RUN stripped oracles)

| Shell | Why it matters / cohort | Grade |
|---|---|---|
| **dash** (`>=0.5.12`) | Debian/Ubuntu `/bin/sh`; the reference host + differential-test oracle. DESIGN pins executor `>=0.5.13` (mainline pipefail). Dialect *floor* can sit at 0.5.12 (Debian pipefail backport) or lower if pipefail isn't in-dialect. | **LOAD-BEARING** (the anchor) |
| **busybox ash** | Alpine `/bin/sh`, Docker base images, OpenWrt, Synology, embedded — the tier-B world (`plans/139`). Has `local` (dynamic), `command -v`, `getopts`, `pipefail` (since 2010). Ubiquitous in the homelab/container niche Dorc names first. | **LOAD-BEARING** |
| **bash-as-`sh`** (POSIX mode) | RHEL/Fedora/CentOS/Arch `/bin/sh`; macOS `/bin/sh`. A strict superset of the floor — the *easiest* host. | LOAD-BEARING (trivially) |
| **FreeBSD `/bin/sh`** (ash desc.) | BSD tier-A; has `local`, close to dash. | LOAD-BEARING iff BSD claimed |
| **OpenBSD `/bin/sh`** (pdksh/oksh), **NetBSD sh** | BSD tier-A; OpenBSD sh = ksh-derived, has `local`. | droppable-ish (BSD reach; low-priority) |

### Consumer daily-driver cohort (oracle bytes must SURVIVE paste)

| Shell | Why it matters | Grade |
|---|---|---|
| **bash >=4 native** | The dominant consumer shell (Linux, WSL). POSIX bytes run fine; superset. | **LOAD-BEARING** (safe) |
| **bash 3.2** (macOS `/bin/bash`) | Still the `/bin/bash` on every Mac; `/bin/sh` = bash-3.2-in-POSIX-mode via `/private/var/select/sh`. Served automatically because we're POSIX-floored (no bash-4-only constructs). | **LOAD-BEARING** (auto-served) |
| **zsh native** | **The hard case.** macOS default *login* shell since Catalina; a huge dev cohort daily-drives it. Pasted oracle bytes run under **zsh semantics, not `emulate sh`** — and zsh native (i) does **not** word-split unquoted `$var`, (ii) **errors** (NOMATCH) on unmatched globs and aborts the command. Discipline covers it (quote-everything; the glob case is a rarer residual). Cannot be dropped. | **LOAD-BEARING** (forces quote-as-law) |

### Explicitly OUT / tolerated

| Shell | Disposition | Cost |
|---|---|---|
| **ksh93** | **OUT of consumer care-set.** Set-membership *is* the ruling: ksh93 has **no `local` at all** (Austin 767), and `typeset` scopes **only** in `function name{}` form, *not* `f()`. Including ksh93 ⇒ `local` banned ⇒ r23-h3 gutted. | Exclusion cost ≈ 0 (ksh93 daily-drivers are AIX-legacy holdouts). Inclusion cost = the whole `local` lean. Easy: OUT. +SURE |
| **mksh** (Android `/system/bin/sh`) | **Free-rider** — has `local` (dynamic), supports the floor; dialect already survives it. Not targeted, not costed. Revisit only if an Android target surfaces. | ~0 |
| **posh** | **Adopt as CI differential-test target**, not a care-set member — it is *literally* Debian's shell for catching §10.4 violations (the contract we mirror). | negative (it's a tool) |
| **yash** | Droppable cohort; optional strict-POSIX differential-test target (has a POSIXly-correct mode). | negative/low |

## (b) FEATURE MATRIX — delta above the classic-POSIX floor

Grades relative to the proposed care-set (dash / busybox ash / bash 3.2+4/sh-mode /
zsh-native / BSD sh; ksh93 excluded, mksh free-rider). "Discipline" = the rule that
makes the row safe everywhere.

| # | Construct | Grade | Note / discipline |
|---|---|---|---|
| 1 | `local x` (declare, dynamic scope) | **UNIVERSAL** | Debian §10.4 mandates it; universal across care-set *because* ksh93 is excluded. Dynamic scoping everywhere (bash/dash/ash/zsh/mksh). |
| 2 | `local a b c=delta d` (assign-while-localize) | **UNIVERSAL-W/-DISCIPLINE** | Debian §10.4 explicitly requires this exact form. Assignment RHS is *not* word-split (assignment context) — safe. BUT see #3. |
| 3 | `local x=$(cmd)` rc-mask | **UNIVERSAL-W/-DISCIPLINE** | `local`'s own exit status **masks** the command-substitution rc in *all* care-set shells (ShellCheck SC2155). **Discipline: declare-then-assign when the rc is consumed or under `set -e`.** This is the concrete hazard the oracle strictness must model/lint. |
| 4 | `set -o pipefail` | **BREAKS-ON** dash<0.5.12, posh, old busybox | POSIX-2024 now, but a bare `set -o pipefail` in a stripped oracle **hard-crashes** old host sh (`set: Illegal option -o pipefail`) — worse than a silent semantic diff. Keep OUT of the mandatory floor or gate it. See ruling `r-pipefail`. |
| 5 | `command -v` | **UNIVERSAL** | POSIX; the portable `which`/existence-check. All care-set. |
| 6 | `printf` | **UNIVERSAL** | The portable output primitive. |
| 6b | `echo -n` / `echo -e` / echo w/ backslashes | **NOT-PORTABLE** | XSI/dash/zsh `echo` interpret escapes; bash (xpg_echo off) does not; `-n`/`-e` all diverge. **Doctrine: `printf` always; never `echo` with flags/escapes.** (Debian mandating `echo -n`-no-newline is a *host* guarantee, not license to emit it.) |
| 7 | `$(...)` | **UNIVERSAL** | Prefer over backticks (nesting/quoting). |
| 8 | `$((...))` core `+ - * / % ( )` | **UNIVERSAL** | |
| 8b | `**`, `++`, `--` in `$(())` | **NOT-PORTABLE** | `**` bash/ksh/zsh only (dash/ash: no); `++`/`--` non-POSIX. Discipline: avoid. |
| 9 | `${x%p} ${x%%p} ${x#p} ${x##p} ${x:-w} ${x:=w} ${x:+w} ${x:?w} ${#x}` | **UNIVERSAL** | The full classic-POSIX PE set — the meat of defensive sh, fully portable. |
| 10 | `${x/p/r} ${x//p/r} ${x^^} ${x,,} ${x:off:len} ${x@Q}` | **NOT-PORTABLE** | Bash/ksh/zsh-isms; die on dash/ash/posh (SC3057 substring, SC3060 replace). **The offramp trap: exactly what a bash/zsh author reaches for.** Discipline: `case`/`sed`/`printf`. |
| 11 | `[ ]`/`test` core (`-e -f -d -r -w -x -z -n = != !`) | **UNIVERSAL** | |
| 11b | `test -a` / `-o` (binary AND/OR) | **DISCIPLINE: forbid** | POSIX-2024 **removed** them (obsolescent); Debian §10.4 still *mandates* them — so they RUN everywhere but are ambiguous. Use `[ ] && [ ]` / `\|\|`. |
| 11c | `[[ ]]`, `==` inside `[ ]` | **NOT-PORTABLE** | bash/ksh/zsh; dash/ash/posh reject. Discipline: `[ ]` with `=`. |
| 12 | `read -r` | **UNIVERSAL** | Bare `read` mangles backslashes — always `-r`. `read -d`/`-p`/`-a`: non-portable (`-d` newly POSIX-2024). |
| 13 | `getopts` (builtin) | **UNIVERSAL** | POSIX. The external `getopt` is NOT (GNU vs BSD divergence) — builtin only. |
| 14 | `f() { ... }` | **UNIVERSAL** | |
| 14b | `function f { ... }` | **NOT-PORTABLE** | SC2112; dash/posh reject. (Also the ksh93 scope-by-form trap — moot given exclusion.) Discipline: `f()` only. |
| 15 | `set -e` divergences | **UNIVERSAL-W/-DISCIPLINE** | (errexit already designed, round 20V.) The one oracle-relevant disagreement: `local x=$(false)` — the `local` *succeeds*, so `-e` does **not** fire on the inner failure (same root as #3). Discipline: declare-then-assign. `-e`-in-`if`/`&&`-LHS suppression *is* portable. |
| 16 | `trap` EXIT + signal **names** (INT/TERM/HUP) | **UNIVERSAL** (note-tier) | `trap - SIG` reset universal. Numeric signals: Debian mandates, POSIX allows names — prefer names. `ERR`/`DEBUG`/`RETURN`: NOT-PORTABLE. (`trap` disposition is separately human-DEFERRED, `notes/276`.) |
| 17 | IFS / unquoted word-splitting | **UNIVERSAL-W/-DISCIPLINE** | **The zsh divergence.** Native zsh does *not* split unquoted `$var`. Dialect must **never depend on word-splitting of an unquoted expansion** to survive paste into zsh. Discipline: **quote everything**; when splitting is *wanted*, do it explicitly (`IFS=…; set -- $x`) in an sh-context. Biggest single rule. |
| 18 | glob / nomatch | **BREAKS-ON zsh-native** | Native zsh errors (NOMATCH) on unmatched glob & aborts; bash/dash pass the literal through. Discipline: quote globs meant literally; don't rely on nomatch-passthrough. Rarer than #17. |
| 19 | `set -u` + `${1-}` / `${VAR-}` | **UNIVERSAL** | Portable everywhere; reference maybe-unset params as `${x-}`. |
| 20 | `>f 2>&1`, `n>&m`, `>|`, `<>` | **UNIVERSAL** | |
| 20b | `&>`, `&>>`, `\|&` | **NOT-PORTABLE** | bash/zsh only. Discipline: `2>&1` form. |
| 21 | `$'...'` (dollar-single-quote) | **UNIVERSAL-W/-CAVEAT** | POSIX-2024 (§2.2.4); dash>=0.5.11 (2018), recent busybox, bash/ksh/zsh/mksh. BREAKS-ON ancient dash/busybox, posh. Floor-dependent — safe if dialect floor is "2024-ish sh"; mild risk on an old Synology. |
| 22 | here-doc `<<` / `<<-` | **UNIVERSAL** | |
| 22b | here-string `<<<` | **NOT-PORTABLE** | bash/ksh/zsh/mksh; dash/ash/posh no (SC3011). Discipline: here-doc or `printf … \|`. |
| 23 | `wait`, `$!` | **UNIVERSAL** | `wait -n`: bash-4.3+ only. |
| 24 | `umask`; `ulimit` (common flags) | **UNIVERSAL-W/-DISCIPLINE** | `umask` fully portable; `ulimit` present everywhere but flag-set varies (Issue-8 pinned `-HSacdnstvf`). Stick to common flags. |

**The 8 most decision-relevant rows:** #3 (local rc-mask), #4 (pipefail crash),
#6b (echo doctrine), #10 (extended-PE offramp trap), #11b/c (`test -a/-o` + `[[ ]]`),
#14b (function keyword), #17 (zsh word-split → quote-as-law), #21 (`$'...'` floor).

## (c) POSIX.1-2024 (Issue 8) PIN-DOWNS

Source: The Open Group Base Specifications Issue 8 / IEEE Std 1003.1-2024
[A-posix-issue8-2024]; the Issue-7→8 Shell&Utilities rationale changelog
[A-posix-issue8-rationale-2024]; cross-checked against the Sortix change-comb
[B-sortix-posix2024].

- **`local` — NOT standardized. +SURE.** The authoritative "New Utilities in
  Issue 8" list is exactly `gettext msgfmt ngettext readlink realpath timeout
  xgettext` — `local` is absent, and it is in no new-feature column. Austin Group
  **defect 767 ("Add built-in local")** shows it was *proposed* and stalled on
  dynamic-vs-static scoping disagreement; the ticket itself records "AT&T ksh93
  doesn't have a `local` built-in at all." **The r23-h3 phrase "POSIX2024-ish,
  which carves out `local` without specifying it" is exactly accurate.**
- **`set -o pipefail` — STANDARDIZED. +SURE.** Added to Issue 8 (`set` special
  built-in); ShellCheck SC3040 confirms "POSIX.1-2024 introduced pipefail … dash
  0.5.13 included pipefail." dash pipefail: mainline 0.5.13, Debian backport
  0.5.12-7. busybox ash since 2010.
- **`$'...'` dollar-single-quotes — STANDARDIZED. +SURE.** New §2.2.4
  "Dollar-Single-Quotes"; the chapter-2 overview step 4 explicitly names
  "backslash-escape sequences inside dollar-single-quotes."
- **`readlink` / `realpath` — STANDARDIZED as utilities. +SURE.** Both in the
  "New Utilities in Issue 8" list; also `realpath -Ee`.
- **Also landing in our matrix (Issue 8): +SURE.** `test -ef`/`-nt`/`-ot` and
  `test` string `>`/`<` now standard; **`test -a`/`-o`/`( )` binary operators
  REMOVED** (matrix #11b — obsolescent-then-gone); `read -d` added; `ulimit
  -HSacdnstvf`; `find -print0`; `timeout` utility; `command`/`cd -e`.

**Load-bearing conclusion:** r23-h3's "carves out `local`" is confirmed genuine —
Issue 8 really omits `local` while Debian really mandates it, so "dash + local"
is the precise, well-precedented description of the target, *not* a fudge.

## (d) CANDIDATE RULINGS — the shortest closing list

Each: question · evidence pointer · recommendation + certainty.

- **`r-careset-ksh93` — ksh93 IN or OUT of the consumer care-set?**
  Evidence: Austin 767 (no `local`; `typeset` scopes only in `function{}` form).
  → **OUT.** Membership *is* the `local` ruling; including it kills r23-h3, and
  ksh93 daily-drivers are AIX-legacy only. **+SURE.**

- **`r-careset-zsh` — native zsh IN-via-discipline or OUT?**
  Evidence: zsh no unquoted word-split + NOMATCH glob-abort (matrix #17/#18).
  → **IN, via-discipline.** Cannot drop (macOS default login shell). Word-split
  is fully covered by quote-as-law; nomatch is a rarer residual. **~SUSPECT** that
  discipline covers 100% (the glob-abort case is the sliver of doubt).

- **`r-careset-mksh` — target or tolerate?**
  → **Free-rider** (tolerated, not targeted; dialect already survives it).
  Revisit only if Android surfaces. **-GUESS** it ever costs anything.

- **`r-careset-testshells` — posh/yash disposition?**
  → **Adopt as CI differential-test targets** (posh = the Debian-§10.4 contract we
  mirror; yash = strict-POSIX), not care-set members. **~SUSPECT** high value/effort.

- **`r-local` — keep `local` in the dialect?**
  Evidence: Debian §10.4 *mandates* `local` incl. `local a b c=delta d`; universal
  across care-set minus ksh93. → **YES — reaffirm r23-h3.** This is the keystone
  that *defines* the dialect: "POSIX + `local`." **+SURE.**

- **`r-local-assign-rc` — the `local x=$(cmd)` mask.**
  Evidence: SC2155. → Dialect **permits** the assign form (Debian requires it) but
  the analyzer treats `local x=$(cmd)` as **rc-opaque** / lints it when the rc is
  consumed or under `set -e`. **+SURE** on the hazard. (Contract detail, not a
  membership call — but it's the concrete thing the strictness buys.)

- **`r-pipefail` — `set -o pipefail` in the mandatory floor?**
  Evidence: POSIX-2024 yes, but BREAKS-ON dash<0.5.12/posh/old-ash with a *hard
  syntax crash*. → **OUT of the paste-survivable floor.** A stripped oracle must
  not contain bare `set -o pipefail`. Pin the *executor* at dash>=0.5.13 (DESIGN)
  but keep the *dialect* floor below it. If pipefail-semantics are needed, gate.
  **~SUSPECT** (depends how hard we commit to old-host paste-survival). This is the
  one place r23-h3's "POSIX2024-ish" over-reaches.

- **`r-printf-doctrine` — printf-only?**
  Evidence: `echo` escape/flag divergence (matrix #6b). → **YES**, never `echo`
  with flags/escapes. **+SURE.**

- **`r-quote-as-law` — quoting is law, not style?**
  Evidence: zsh word-split inversion (#17). → **YES — the single biggest rule.**
  It is what makes the dialect survive the consumer cohort. **+SURE.**

- **`r-function-form` — `f()` only?**
  Evidence: SC2112. → **YES**, forbid `function f {}`. **+SURE.**

- **`r-no-bashfamily-pe` — ban the reach-for constructs?**
  Evidence: SC3057/3060/2039/3011/2112. → Forbid `${x/}`,`${x//}`,`${x^^}`,
  `${x:off:len}`, `[[ ]]`, `==`, `<<<`, `&>`, `\|&`. **These are the offramp trap**
  — the exact constructs a bash/zsh author habitually writes that die on dash/ash.
  **+SURE.**

- **`r-test-ao` — forbid `test -a/-o`?**
  Evidence: POSIX-2024 removed them; ambiguous. → **YES**, use `&&`/`||`. Note the
  Debian-mandates-them tension (they *run*, we just don't *emit*). **+SURE.**

- **`r-dollar-single-quote` — permit `$'...'`?**
  Evidence: POSIX-2024 §2.2.4; dash>=0.5.11. → **PERMIT** (floor is 2024-ish), with
  the known mild risk on ancient busybox/Synology. **~SUSPECT.**

### Bottom line (do not pad)

**The delta above "dash + local" is ~5 disciplinary line-items, not a feature
list:** (1) quote-as-law, (2) printf-only, (3) `f()`-only, (4) declare-then-assign
for rc/`set -e`, (5) no bash-family PE/`[[`/`<<<`/`&>`; plus two membership calls
(ksh93 OUT, zsh IN-via-discipline) and one floor nuance (pipefail below the
executor pin). The maximum-gcd pole buys nothing spendable for oracles, because
the consumer-paste requirement forbids using the richness that admitting bash/zsh
would notionally grant. **r23-h3 stands; refine only "POSIX2024-ish" → "POSIX-2017
+ local + the *safe* subset of Issue-8 (not pipefail as a bare floor requirement)."**
