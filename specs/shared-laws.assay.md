# Shared laws: the append half

The laws assay splices after every specification's own definitions, so a shared law may name a
function each specification defines (`notes/30Y` § 2.2). No law is shared yet: with one
specification in the tier, what a second would have to satisfy is a guess, and a law lifted here
later is a reword the lock must show moves nothing (`30Z:loop-a-reword-moves-nothing`). This
document holds no fence, so it is commentary and binds nothing.
