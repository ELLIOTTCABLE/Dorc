## §6 — The may-alias fire-rate question (24F §3a) — FLAG to human

**24O-may-alias-default — FLAG (future human ruling once data exists).** This is a `tc-*`-shaped
judgment call; per the input's own framing my job is only to state crisply *what data would decide
it and where that data comes from* — never to settle it.

**The question.** When a resolver returns ⊤ / can't-resolve / non-zero rc / malformed output for a
coordinate, the pair's comparison degrades to **MAY-ALIAS ⇒ hit ⇒ demote** (fail toward run), not
to token-equality (`24F` §3a). The default is a **-GUESS**: 24F says "measure how often the degrade
fires; if it swamps the yardstick, that is a finding, not a license to flip the default silently."

**What data decides it.**
1. The `may-alias=N` plan-summary counter (instrumented and LANDED, `24C` Stage-5A) measured across
   a strawman family **at varying resolver quality** — this sizes the mechanism's *sensitivity* (how
   much elision the demote-to-run costs when a resolver is imperfect). This is the TABLED measure/
   maximize half's output — so the sensitivity number is produced by the *tabled* work, once
   re-opened.
2. The **true fire-rate** — how often real resolvers (`dpkg-query -W`, `realpath -m`) actually
   return ⊤/fail on real coordinates on real hosts — is **not answerable on strawmen**: the spike's
   resolvers are *declared* answers (`Host::derive`-style), so they only produce ⊤ when seeded to.
   The real rate comes from the **r25 real-machine differential** (where real resolvers run and
   genuinely fail on virtual/provides/dangling names).

**The decision, when data exists.** If the strawman sensitivity is low *and* the r25 real fire-rate
is low, the -GUESS default (degrade-to-may-alias/run) is confirmed cheap and correct. If the rate
swamps the yardstick, that is a *finding* — but per 24F it is still not a license to silently flip
the default to token-equality (which would trade the cardinal-sin safety direction for value). Any
flip is an explicit, attributed human ruling. I FLAG this for the human, unsettled; the companion
human thread `aliasing-horizon-wording` (`24F` §1/§9) becomes writable in the same window.
