# Falsehoods programmers believe about networks

A consolidated list from Ken Bantoft's *Falsehoods Programmers Believe About Networks*[^1] and Robert Graham's *Falsehoods programmers believe about networks*.[^2] Items stated by both sources are merged and cite both.

1. The network uses RFC1918 IP addresses.[^1]
2. This network block will be unique globally.[^1]
3. A home network is always a `/24` network.[^1]
4. IPv4 is available.[^1]
5. There is no IPv6 on the network.[^1][^2]
6. If there is IPv6, it can be turned off.[^1]
7. There is a DHCP server on the network.[^1]
8. The IP address assigned by DHCP will not change when you try to renew it.[^1]
9. You can turn off DHCP on the network.[^1]
10. You can turn on DHCP on the network.[^1]
11. The default gateway, local router, and DHCP server are the same device.[^1][^2]
12. The default gateway and DNS server are the same device.[^1]
13. There is a DNS server.[^1]
14. That IP address will never change.[^1]
15. You can ping the default gateway.[^1]
16. You can ping at least one other device on the network.[^1]
17. You can reach `google.com`, or any other hardcoded domain.[^1]
18. You can reach the internet.[^1]
19. The MTU is always 1500 bytes.[^1]
20. No one uses PPP anymore.[^1]
21. No one uses multicast anymore.[^1]
22. Multicast over Wi-Fi works just fine.[^1]
23. Wi-Fi and wired connections can be treated the same.[^1]
24. You can block packets other than TCP and UDP and everything will keep working.[^1]
25. Keepalives are free, so they can be used often.[^1]
26. Wi-Fi is free, unlike 3G or LTE.[^1]
27. Latency will always remain below an arbitrary bound such as 2,000 ms.[^1]
28. A network interface has an IP address.[^1]
29. A network interface has a MAC address.[^1]
30. A network interface has only one MAC address.[^1]
31. A network interface has no address.[^1]
32. MAC addresses are unique.[^1]
33. You can identify a device's type from its MAC address.[^1]
34. No one uses the locally administered bit of a MAC address.[^1]
35. No one sets the multicast bit on a source MAC address in violation of IEEE 802.3.[^1]
36. Switches do not filter MAC addresses unless explicitly configured to do so.[^1]
37. `127.0.0.1` is the only loopback IP address ever used.[^1]
38. VLANs fix segregation problems and are equivalent to physical segmentation.[^1][^2]
39. VLAN gateways never leak packets, such as ARP packets, between VLANs.[^1]
40. None of the preceding concerns matter on an IPv6-only network.[^1]
41. Data on the network cannot be altered.[^2]
42. Encrypted data on the network cannot be altered.[^2]
43. Data cannot be accidentally corrupted because TCP has checksums and Ethernet has CRCs.[^2]
44. If something is inside your perimeter firewall, you have total control over it.[^2]
45. If `send()` does not return an error, it sent all the data requested.[^2]
46. Packets arrive in the order in which they were sent.[^2]
47. Segment boundaries on a TCP stream are meaningful to the application.[^2]
48. Segment boundaries on a TCP stream are not meaningful to the application.[^2]
49. If you cannot ping a target, it does not exist.[^2]
50. If you can ping a target, it exists.[^2]
51. TCP RSTs come from end nodes.[^2]
52. Bytes must be swapped from network byte order to the host CPU's byte order.[^2]
53. Outsiders cannot discover an internal web application.[^2]
54. A DHCP address will be the same after a reboot.[^2]
55. A DHCP address will remain the same until the next reboot.[^2]
56. A DHCP address will at least remain unchanged for a long time.[^2]
57. Packets and protocol data units move only up or down the network stack, never sideways.[^2]
58. An IPv4 header is always 20 bytes long and begins with `0x45`; options are too rare to matter.[^2]
59. NAT automatically blocks all inbound attacks.[^2]
60. You know all the devices attached to your network at any given time.[^2]
61. Although VLANs are not as good as physical segmentation, they are good enough for now.[^2]
62. Good wireless intrusion-prevention systems or monitors guarantee that there are no rogue access points.[^2]
63. There is no need to add a host to DNS because you will remember it.[^2]

[^1]: Ken Bantoft, [“Falsehoods Programmers Believe About Networks”](https://medium.com/@kenbantoft/falsehoods-programmers-believe-about-networks-30a328c25c50), 7 November 2019.
[^2]: Robert Graham, [“Falsehoods programmers believe about networks”](https://blog.erratasec.com/2012/06/falsehoods-programmers-believe-about.html), June 2012.
